### About

I co-founded **Kebeta**, a web studio where I turn designs into fast, production-ready marketing websites for startups and growing businesses.

- 🧩 **Webflow** sites built clean, scalable and easy for clients to edit
- 🚀 **Webflow → Astro + Sanity migrations** when a site outgrows its CMS — blogs, case studies, large content libraries
- ☁️ Deployments on **Cloudflare**, version control with **GitHub**
- 🎞️ Interactions and scroll animations with **GSAP**
